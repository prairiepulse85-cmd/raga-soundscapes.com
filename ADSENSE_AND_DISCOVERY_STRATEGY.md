# Raga Soundscapes AdSense and Discovery Strategy

## Current Assumptions

- The site is an educational raga library, not a music streaming product.
- The YouTube channel is separate from the raga library and should not be positioned as pure, formal, or direct raga performance.
- No per-raga outbound YouTube links should appear on the library pages.
- AdSense readiness should come from original informational value, clear ownership/contact signals, privacy disclosure, and responsible claims.

## Critical Audit

- Strong base: the site already has a focused raga library, mood/time organization, individual pages, and beginner-friendly explanations.
- Main positioning risk: language must not imply that the channel contains complete classical raga performances.
- Main AdSense gap: missing trust/legal pages and privacy language.
- Main discovery gap: canonical URLs, sitemap coverage, route metadata, and structured internal navigation needed tightening.
- Main content risk: unverified raga grammar fields should remain explicitly marked as unverified rather than filled from memory.

## Design Analysis

- First impression: the site had a clear cultural tone, but the old first screen was almost entirely text and did not create enough emotional pull for a visitor arriving from YouTube.
- Readability: secondary text used very low-contrast blue-gray on a dark background. That looked atmospheric, but it made scanning harder, especially on mobile and for longer educational copy.
- Palette: the old palette leaned heavily into one dark blue/gold family. It felt calm, but also flat. A small teal accent and warmer text contrast make the library feel more premium without becoming colorful.
- Hierarchy: headings were elegant, but too many sections used the same centered title/card-grid rhythm. The page needed a stronger first viewport, clearer start path, and a more useful library control area.
- Cards: raga cards were compact but under-informative. The new cards use larger type, more breathing room, and a consistent learning-guide signal.
- AdSense readiness: readability and trust matter more than aggressive monetization. The best design path is a polished educational site with clear policy pages, not early ad-heavy layouts.

## Recommendation Critique and Final Alignment

- Add a hero visual: accepted. It improves memorability and perceived quality. Risk is distraction, so the image is restrained, text-safe, and culturally suggestive without religious or performer claims.
- Increase contrast: accepted. This directly improves readability and review quality.
- Make the site more colorful: partially rejected. A richer accent system helps, but an overly bright music-site palette would hurt the calm educational positioning.
- Add aggressive YouTube CTAs: rejected. The site should not look like a doorway page to YouTube. Keep only a generic channel link near the bottom of the page.
- Add ad placeholders immediately: rejected. Empty ad slots before AdSense approval make the site feel thin and commercial. Add ads only after approval and only between content sections.
- Fill unverified raga grammar fields: rejected for now. Accuracy and trust are more important than completeness.

## Implemented Optimization

- Added public trust pages: About, Contact, Privacy Policy, Terms, Editorial Policy, and Disclaimer.
- Added global header navigation and expanded footer links so reviewers and users can reach key pages.
- Normalized canonical URLs and sitemap entries to `https://www.ragasoundscapes.com`.
- Removed per-raga YouTube CTAs and clarified that the channel is separate from the educational library.
- Added stronger homepage metadata and WebSite structured data.
- Added repo notes so future changes preserve the educational and AdSense-safe positioning.
- Added per-raga educational notes that explain character, beginner cues, and listening identity without inventing unverified swara notation.

## YouTube Link Use

Use this wording pattern for generic channel mentions only:

> The YouTube channel is separate from this raga learning library and should not be treated as a formal classical raga archive.

Avoid:

- "Pure raga"
- "Authentic performance"
- "Healing guarantee"
- "Cures sleep/anxiety"
- "Classical demonstration" unless the track has been reviewed as such
- Per-raga "listen on YouTube" buttons

## AdSense Before-Apply Checklist

- Privacy, Contact, About, Terms, Disclaimer visible in footer.
- No placeholder ads.txt.
- No empty or thin pages indexed without useful content.
- No medical or guaranteed wellness claims.
- Sitemap returns all important public routes.
- No individual raga page depends on or promotes a raga-specific YouTube link.
- Mobile layout is readable and navigable.
